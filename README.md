# 🎬 Movie Website – Next.js

A modern and responsive movie & TV series website built with **Next.js**, using **TMDB API** to display up‑to‑date movie information.

---

## 📌 Overview

This project is a **movie and series website** developed with **Next.js**.
It allows users to browse movies, view details, ratings, trailers, and discover trending or popular content.

The project is built mainly for **learning, practice, and portfolio purposes**, focusing on clean architecture, performance, and modern UI design.

---

## ✨ Features

- 🎥 Browse popular, trending, and upcoming movies
- 📄 Movie & TV series details page
- 🌟 Ratings, overview, genres, and release date
- 🔍 Search movies and series
- 📱 Fully responsive design (mobile & desktop)
- ⚡ Fast loading with Next.js optimization
- 🎨 Clean and modern UI
- 🧩 Reusable components (MovieCard, Skeletons, Navbar, etc.)

---

## 🛠 Tech Stack

- **Next.js**

## 🚀 Getting Started

Follow these steps to set up the project locally.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/riapou/nextjs-movie-app
cd nextjs-movie-app
```

### 2️⃣ Install dependencies

```bash
npm install
# or
yarn install
```

### 3️⃣ Environment Variables

Create a `.env.local` file in the root directory and add your TMDB API key:

env
NEXT_PUBLIC_TMDB_API_KEY=your_api_key_here

> You can get your API key from: [https://www.themoviedb.org/](https://www.themoviedb.org/)

### 4️⃣ Run the development server

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
